# Security policy

Please report credential exposure, unsafe hardware behavior, and
security-sensitive memory, CUDA, storage, trace, or model-parsing bugs privately.
Do not open a public issue containing secrets, personal identifiers, exploit
details, or unsafe reproduction commands.

No security email address is published. Where GitHub private vulnerability
reporting is available, use it; otherwise contact the repository owner through
an appropriate private GitHub channel before public disclosure.

Sidecar is experimental research software that can allocate large buffers and
stress GPUs and storage. Review plans and safety limits before execution.
